# Data

The M5 data is **not** in this repository. Its use is governed by the Kaggle competition's terms, and the files total about 450 MB.

## Download
1. Sign in to Kaggle and accept the rules of the [M5 Forecasting – Accuracy](https://www.kaggle.com/competitions/m5-forecasting-accuracy) competition.
2. Download the data, either from the competition's **Data** tab or with the Kaggle CLI:
   ```bash
   kaggle competitions download -c m5-forecasting-accuracy
   ```
3. Unzip into `data/raw/`. The pipeline reads three files:
   - `data/raw/sales_train_evaluation.csv`: daily unit sales, d_1 to d_1941 (2011-01-29 to 2016-05-22)
   - `data/raw/calendar.csv`: dates, events, SNAP days per state
   - `data/raw/sell_prices.csv`: weekly sell prices per store and item

The raw files are never modified. Everything in `data/interim/` and `data/processed/` is regenerated by the notebooks (`make notebooks`).

## What is committed
- `outputs/tables/`: result tables. `scripts/build_facts.py` computes every headline number from them, and the dashboard reads them.
- `outputs/tables/app/`: compact copies used by the dashboard.

Two large daily tables (`pbi_fact_forecast_daily.csv`, `pbi_fact_inventory_daily.csv`) are git-ignored and rebuilt by notebook 04.
